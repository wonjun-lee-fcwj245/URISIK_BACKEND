# 폐기된 1차 실행 (shared-iterations)

`shared-iterations`(VU 100, iterations 100)는 VU가 반복을 균등하게 1회씩 가져간다는 보장이 없다.
빠른 VU가 2회를 가져가면 같은 memberId가 같은 레시피에 두 번 요청해 409(중복 리뷰)가 나고,
다른 유저 하나는 요청하지 않는다. 그래서 "성공/전체"가 실제 동시성 결과와 무관하게 99/100, 199/200처럼 나왔다.
(2026-11-05 review-v2-run3.log의 "99건 + 중복 1건"도 같은 원인으로 추정된다.)

이 실행 결과는 지표 정의가 달라 집계에서 제외하고, `per-vu-iterations`(VU당 정확히 1회)로 다시 측정했다.
정합성(counter 불일치 0, avg_score 절반 버그)은 이 실행에서 처음 발견되었고 재측정에서도 확인했다.
